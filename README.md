# 파문 — THE RIPPLE

작은 선택이 서로 모르는 사람들의 하루에 어떤 흔적을 남기는지 관찰하는 오리지널 인생 시뮬레이션.

## 실행
GitHub Pages를 활성화하면 저장소 루트의 `index.html`에서 바로 실행할 수 있습니다. 별도 빌드 도구나 서버는 필요하지 않습니다.

## 현재 버전
- 월요일부터 일요일까지 이어지는 7일간의 도시 시뮬레이션
- 8명의 인물별 기분, 에너지, 희망, 신뢰 상태
- 선택에 따른 인물 상태 변화와 도시 지표 누적
- 하루가 지날 때마다 진행되는 인물 상태의 시간 경과
- 마지막에 도시 전체 지표, 선택의 파급 기록, 인물별 주간 리포트 제공
- 데스크톱과 모바일 반응형 UI 및 모션 최소화 설정 지원

## 설계 원칙
- 기존 작품의 화면, 문장, 캐릭터, 진행 구조를 복제하지 않습니다.
- 감동을 강요하는 대신 선택의 결과와 인물의 일상을 통해 여운을 만듭니다.
- 플레이어가 모든 결과를 통제할 수 없다는 점을 게임의 일부로 둡니다.

## 현재 한계
현재는 7일의 주요 사건과 선택지가 설계된 내러티브 시뮬레이션입니다. 인물의 상태는 선택에 따라 변화하지만, 인물들이 완전히 자율적으로 행동하거나 사건을 무한히 생성하는 단계는 아닙니다. 이후 관계망, 장기 기억, 자율 일정, 예측하기 어려운 사건을 확장할 수 있도록 구조를 발전시킵니다.

# 파문 — THE RIPPLE

작은 선택이 서로 모르는 사람들의 하루에 어떤 흔적을 남기는지 관찰하는 인터랙티브 인간 시뮬레이션.

## 실행
GitHub Pages를 활성화하면 저장소 루트의 `index.html`에서 바로 실행할 수 있습니다. 별도 빌드 도구나 서버는 필요하지 않습니다.

## 현재 프로토타입
- 5일에 걸친 짧은 도시 관찰 시뮬레이션
- 선택에 따라 달라지는 사람들의 연결 기록
- 마지막에 플레이어가 남긴 흔적을 모아 보여주는 엔딩
- 모바일 화면 대응

이 프로젝트는 기존 작품의 화면·문장·진행 구조를 복제하지 않고, 작은 행동이 타인의 삶에 미치는 영향을 독자적인 방식으로 표현합니다.

# 삶의 궤적 — A LIFE, IN MOTION

한 인물의 어린 시절부터 노년까지를 살아보며 선택과 관계, 시간의 흐름을 돌아보는 오리지널 인생 시뮬레이션.

## 실행
저장소 루트의 `index.html`을 브라우저에서 열거나 GitHub Pages를 활성화해 실행할 수 있습니다. 별도 빌드 도구는 필요하지 않습니다.

## 현재 버전
- 한국어, 영어, 일본어, 중국어(간체) 지원 및 진행 중 언어 변경
- 플레이어 이름 직접 입력 또는 언어별 무작위 이름 생성
- 새 삶마다 무작위로 생성되는 주변 인물 이름과 고정된 인물 정체성
- 6세부터 82세까지 이어지는 10개 인생 시기
- 선택에 따라 변화하는 건강, 마음의 여유, 배움과 경험, 주변 인물과의 관계
- 선택 결과를 시간의 흐름과 함께 기록하는 인생 일지 및 최종 회고
- 모바일·데스크톱 반응형 화면

## 설계 원칙
- 플레이어는 관찰자가 아니라 이야기의 주인공입니다.
- 주변 인물의 이름은 새 삶마다 무작위로 생성되며, 한 번 생성된 이름은 해당 삶이 끝날 때까지 유지됩니다.
- 선택에는 정답이 없으며, 모든 결과를 점수 하나로 평가하지 않습니다.
- 기존 게임의 문장, 인물, 화면, 진행 구조를 복제하지 않습니다.

## 현재 한계
이번 버전은 인생의 주요 시기를 선택형 사건으로 구성한 서사 시뮬레이션입니다. 나이와 선택에 따라 주요 상태와 인물 관계가 누적되지만, 인물들이 독립적인 일정과 욕구를 가지고 자율적으로 행동하는 완전한 사회 시뮬레이션은 아닙니다. 다음 개발 단계에서는 주변 인물과의 구체적인 관계사, 장기 기억, 사건 간 인과관계, 예측하기 어려운 일상 사건을 강화해야 합니다.

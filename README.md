# DIAMOND — Baseball Career

브라우저에서 실행하는 야구 커리어 게임의 첫 번째 플레이어블 기반입니다.

## 실행
- GitHub Pages를 켜고 저장소 루트를 배포하면 index.html에서 시작합니다.
- ES Modules로 실행하며, Three.js는 첫 화면이 그려진 뒤 idle 시점에만 CDN에서 지연 로드합니다.
- 현재 빌드에는 로그인·서버 저장·브라우저 자동 저장이 없습니다.

## 구현된 1차 기능
- 첫 화면에서 선수 커리어 / 구단 운영 모드 선택
- 선수 생성: 포지션, TWP 여부, 타자·투수 유형
- 초기 능력치 3회 배분: 선택 1회당 지정 능력치 +5, 확정 전 변경 가능
- 구단별 포지션 수요를 반영한 드래프트
- 선수 레벨 및 경험치
- 1성~5성 카드의 레벨·성적 기반 획득
- 국대 / 올스타 / TOP / ICON / 골든글러브 카드의 시즌 평가 구조
- 카드별 독립 강화, 기본 능력치, 수상 보너스, 육성 능력치 분리
- 카드 선택, CPU 경기 시뮬레이션, 시즌 진행, 커리어 기록
- 가상 구단 10개와 구단별 색상·연고지·독자 구장 설정
- Three.js 기반 절차적 3D 구장 미리보기, 드래그 회전 및 확대/축소
- 선호 구단 선택과 드래프트 선호도 반영
- 별 등급별 카드 색상 체계와 국대·올스타·TOP·ICON·골든글러브 전용 색상
- 포지션 전환 가능 범위와 적합도 계산 모듈

## 카드 능력치 원칙
최종 능력치는 기본 능력치 + 기본 능력치 추가량 + 육성 능력치로 계산합니다.
시즌 재평가는 기본 능력치만 변경합니다. 수상·재선정으로 쌓인 추가량과 카드별 강화·육성은 보존합니다. 카드마다 기본 능력치와 최대 강화 단계는 서로 다를 수 있습니다.

## 아직 구현하지 않은 기능
- 실제 선수 모델·고해상도 PBR 재질·애니메이션을 포함한 사실적인 경기 3D와 타격·투구·수비 직접 조작
- 실시간 온라인 대전 및 비동기 유저 데이터 대전 서버
- 서버 계정, 클라우드 세이브, 멀티 디바이스 동기화
- 전체 선수단 로스터, 영입·트레이드, 계약·연봉
- 은퇴 후 코치·감독 커리어
- 구단별 시즌 스케줄, 상세 리그 순위 및 포스트시즌
- 밸런스 확정용 실제 통계 데이터

구장 미리보기는 실제 KBO 구장을 복제한 모델이 아니라, 도시 분위기와 야구장 유형을 참고해 새로 구성한 절차적 가상 모델입니다. 현재는 첫 3D 렌더링 기반 단계로, Unity급 사실적 품질이나 실제 경기 플레이를 의미하지 않습니다. 실제 KBO 구장의 건축 디자인을 그대로 3D 복제하는 것은 저작권 검토가 필요합니다.\n\n현재 시즌 활약과 경기 결과는 시스템 흐름 확인을 위한 테스트용 수치 모델이며, 실제 경기 성능이나 리그 밸런스를 대표하지 않습니다.
